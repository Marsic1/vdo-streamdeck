# Plugin reliability review — 2026-09-04

Fixed four reproduced defects using the existing transport and dial queues:

- Late HTTP successes/errors from a removed or changed API connection could overwrite current connection status and deliver stale callbacks. Requests now check the connection generation before updating state or emitting callbacks. The startup probe also preserves the transport's specific error state.
- A valid JSON `null` relay message could crash the plugin; malformed callback/update envelopes could claim a connection. Only object envelopes are processed.
- Queued value/PTZ rotations could execute against the next control after a dial press, and a queued value could undo a reset. These presses now discard superseded input; stale rotation completions cannot overwrite the new control's feedback or saved value.
- Lowering a value dial's maximum while input was queued caused endless repeats of the clamped value. Queue completion now compares against the requested value.

Added ten regression cases under `plugin/tests/`. The original suite passed before these changes; the new reproductions failed before their respective fixes.

117 tests pass. Build, isolated bundled-runtime integration, and manifest validation pass. The runtime integration uses the official SDK with simulated Stream Deck events and a local API relay; it covers all action types, polling, persistence, and feedback readback. Live hardware, actual Stream Deck UI rendering, and public-relay end-to-end behavior remain unverified in this review. The installed plugin was not replaced.

## Continued review and UX improvements

- Added 25 command glyphs using the existing generated vector/raster system. Local/guest command definitions select their artwork through the registry; PTZ and mixer keys distinguish their controls. White symbols now sit above the title instead of appearing as faint marks behind the text. Unknown action state uses neutral artwork.
- Inspector changes repaint key labels and images immediately without requiring a connection or button press. Repeated state refreshes reuse the same artwork; native custom-image overrides remain supported.
- Reproduced out-of-order momentary mic requests and missing release after changing a held key's behavior. Press/release requests are now ordered, and changing the behavior or leaving the profile releases the original mic action.
- Reproduced Test connection returning cached success without contacting the page. Both HTTP and WebSocket tests now require a fresh response.
- Moved the existing runtime smoke harness into `plugin/tests/` and extended it to verify packaged command images, immediate inspector feedback, and native SDK profile-disappearance cleanup.

The expanded suite passes 129 tests. The updated bundled-runtime smoke passes. Windows computer-use could not connect to its native helper, so actual Stream Deck UI/hardware validation remains unverified. No installed plugin or user profile was modified.
